A machine client should resolve resource state before payment.

Recommended sequence:

```text
resource identity
↓
resource existence
↓
resource completeness
↓
access class
↓
price
↓
402 when protected and eligible
```

Do not use:

```text

↓

↓
assume resource exists
```

Unknown resource:

```text

no payment challenge
```

Known but incomplete resource:

```text
409
no payment challenge
```

Registered, complete, protected resource:

```text
eligible for 402
```

This prevents public discovery or syntactically valid routes from being misinterpreted as automatically payable products.
