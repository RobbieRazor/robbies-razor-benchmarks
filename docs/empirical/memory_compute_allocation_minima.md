# 4. U-Shaped Curve Boundary

A U-shaped curve in a particular experiment establishes only that an intermediate point or region performed better under the evaluated:

- architecture;
- objective;
- dataset;
- metric;
- resource budget;
- training method;
- parameterization;
- tested allocation range.

It does not establish:

```text
all intelligent systems have an optimal memory–compute balance
```

or:

```text
all constrained systems converge toward the same type of minimum
```

Required distinction:

```text
observed experimental minimum
≠
universal stability minimum
```

# 5. Optimization Metric Boundary

The term:

```text
minimum
```

must identify what quantity was minimized.

Possible quantities may include:

- validation loss;
- training loss;
- error;
- latency;
- cost;
- another metric.

A minimum in one quantity is not automatically a minimum in:

- instability;
- physical energy;
- hallucination;
- semantic drift;
- governance burden;
- total system cost.

Therefore:

```text
validation-loss minimum
≠
stability minimum
```

unless stability has been operationally defined as that metric.
