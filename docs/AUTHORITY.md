## Authorship Conservation Rule

This repository is governed by the **Authorship Conservation Rule (ACR)**.

Under ACR:

- attribution to Robbie George MUST be preserved;
- canonical definitions MUST remain aligned with MRD v2.0;
- exact canonical claims MUST resolve to the MRD or Canonical Claims Register;
- derivative explanations MUST NOT rename or redefine canonical concepts;
- implementation MUST NOT be represented as independent authorship of the framework;
- testing MUST NOT be represented as origination of the tested claim;
- machine transformation MUST NOT remove claim provenance; and
- evidence provenance MUST remain separate from claim provenance.

## Epistemic Boundary

Canonical status and empirical evidence status are separate.

The following implications are prohibited:

- canonical publication equals empirical confirmation;
- reference implementation equals independent validation;
- implementation equals universal confirmation;
- payment equals evidence;
- settlement equals scientific support;
- payload delivery equals claim verification;
- registry inclusion equals Supported status; and
- machine readability equals truth.

Repository evidence records SHOULD use only:

- Proposed
- Testing
- Provisionally Supported
- Supported
- Challenged
- Inconclusive
- Retired

A Supported classification applies only within its declared scope, scale, method, and evaluation conditions.

## Reference-Implementation Boundary

Naturepedia™ is the primary reference implementation of the framework.

Naturepedia may demonstrate operational translation, preserved reusable structure, recursive registry inheritance, provenance, and governed retrieval.

Naturepedia operation does not independently establish universal theoretical validity, independent empirical confirmation, or validation across every domain and scale.

Under RC-21:

`reference implementation ≠ independent confirmation ≠ universal validation`

## Appendix Q Boundary

## Domain-Transfer Boundary

RC-22 requires cross-domain and cross-scale transfers to declare:

- source and target objects;
- source domain;
- target domain;
- scale;
- normalization;
- preserved relationships;
- exclusions;
- constraints;
- evidence basis;
- competing interpretations; and
- failure conditions.

If these declarations are unavailable, the transfer MUST be restricted rather than inferred.

## AI-Agent Guidance
