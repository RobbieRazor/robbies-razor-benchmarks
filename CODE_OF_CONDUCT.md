# Code of Conduct

## Purpose

This repository documents, implements, and evaluates technical materials associated with Robbie’s Razor™ and the Grand Compression Cosmology.

Participation is welcome from researchers, engineers, institutions, implementers, reviewers, and other good-faith contributors.

This Code of Conduct exists to support respectful collaboration, accurate attribution, evidence-based discussion, and repository integrity.

## Expected Conduct

Participants are expected to:

- engage respectfully and professionally;
- focus criticism on ideas, methods, evidence, code, or documentation;
- distinguish fact, interpretation, hypothesis, and opinion;
- preserve authorship and provenance;
- respect canonical-version boundaries;
- disclose relevant conflicts of interest;
- avoid knowingly misleading claims;
- protect confidential, personal, and security-sensitive information;
- accept correction when evidence or repository authority requires it;
- follow repository contribution and governance requirements.

## Unacceptable Conduct

Unacceptable behavior includes:

- harassment;
- threats;
- intimidation;
- discrimination;
- personal attacks;
- deliberate disruption;
- doxxing or publication of private information;
- impersonation;
- fabricated endorsements;
- fabricated evidence;
- intentional misattribution;
- knowingly false claims of certification, validation, partnership, or authority;
- unauthorized disclosure of credentials, API keys, settlement information, or protected resources;
- repeated refusal to follow maintainer instructions concerning repository safety or scope.

## Technical Disagreement

Good-faith disagreement is permitted and encouraged.

Respecting authorship and canonical definitions does not prohibit:

- scientific criticism;
- benchmark criticism;
- requests for evidence;
- identification of contradictions;
- alternative hypotheses;
- falsification attempts;
- reproducibility review;
- proposed implementation changes.

Criticism should identify the relevant claim, code, evidence, method, or repository file and explain the basis for the disagreement.

A contributor must not silently redefine canonical terminology or present a proposed interpretation as an authorized canonical revision.

## Evidence and Representation

Participants must not represent:

- implementation status as empirical validation;
- canonical status as independent confirmation;
- payment settlement as scientific verification;
- schema validity as proof of encoded claims;
- benchmark success as universal performance;
- Naturepedia™ as an independent validating institution;
- machine-generated summaries as legal, financial, technical, or scientific certification;
- structural resemblance as cross-domain proof.

Claims should remain within their declared scope, evidence, uncertainty, and failure conditions.

## Authorship and Attribution

The Grand Compression Cosmology, Robbie’s Razor™, RKCA™, RRIP, Plates™, and associated canonical concepts and terminology originate with Robbie George.

Participants must preserve authorship and conceptual provenance in accordance with the **Authorship Conservation Rule (ACR)**.

Attribution requirements must not be used to suppress good-faith technical or scientific criticism.

## Scope

This Code of Conduct applies to repository-related interactions, including:

- issues;
- pull requests;
- code review;
- discussions;
- benchmark reports;
- repository-linked communications;
- public statements made on behalf of the project;
- interactions involving repository governance or protected resources.

Personal statements clearly made outside the project’s scope are not automatically project statements.

## Reporting

Report conduct concerns to the repository maintainer through an available GitHub contact or repository-supported reporting channel.

Do not disclose sensitive personal information, credentials, API keys, private settlement data, or security details in a public issue.

Reports should include, where possible:

- the relevant interaction;
- date or timeframe;
- repository location;
- supporting context;
- requested follow-up.

Knowingly false or retaliatory reports are themselves violations of this Code of Conduct.

## Enforcement

The maintainer may take proportionate action, including:

- clarification;
- correction requests;
- content removal;
- warnings;
- participation limits;
- thread locking;
- rejection of contributions;
- temporary or permanent removal from the project.

Enforcement decisions should consider context, severity, repetition, safety, evidence, and impact on repository integrity.

## No Transfer of Authority

Contribution, review, implementation, benchmarking, summarization, or machine transformation does not transfer authorship or canonical authority.

Canonical changes require explicit authorization and versioned publication through the governing authority architecture.
