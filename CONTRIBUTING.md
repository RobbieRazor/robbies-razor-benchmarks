# Protected-Resource Availability Boundary

A route pattern does not establish that a protected resource exists.

Required production semantics are:

```text
Unknown resource
→ HTTP 404
→ no payment challenge
```

```text
Known but incomplete resource
→ HTTP 409
→ no payment challenge
```

```text
Registered and complete resource
→ eligible for governed HTTP 402 challenge
```

Contributors MUST NOT make a route issue a payment challenge solely because its URL matches a protected route pattern.

Resource availability must be established before payment challenge generation.
